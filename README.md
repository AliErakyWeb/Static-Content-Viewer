# Static Content Viewer

A simple full-stack web application built with Node.js and Express.

## Features

- Displays predefined static content.
- Serves content through a backend API.
- Renders the content on a simple frontend.
- Responsive design for desktop and mobile screens.

## Technologies

- HTML
- CSS
- JavaScript
- Node.js
- Express

## Installation

1. Install Node.js.
2. Open a terminal in the project folder.
3. Install dependencies:

   npm install

## Run the Application

Start the server:

npm start

Open the following URL in your browser:

http://localhost:3000

## API Endpoint

GET /api/content

Returns the predefined title and message in JSON format.
